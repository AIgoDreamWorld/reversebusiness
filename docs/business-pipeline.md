# ReverseBusiness — 근거 검증형 사업 발굴·REA 재사용 공정

기준: 2026-11-21 KST | 브랜치: `feat/governed-business-pipeline-v1` | WJ 최종 승인 책임 유지.

## 북극성

아이디어/URL → 실제 서비스·콘텐츠 후보 최대 10개 → 독립 검증·리스크 필터 → 사업 전략 3개 → **WJ 명시적 사업 승인** → 기존 REA 복원 자산 검색·재사용 → 별도 독립 실행기 제작 → 실물·시장 QA → WJ 출시 판단.

**실패율 0%를 보증할 수는 없다.** 대신 실제 시장 자료 없이는 투자·제작으로 넘어가지 않는 차단 장치를 두고, 실패의 비용을 제한한다.

## 이번 버전에서 실제 구현한 것

- `lib/opportunity-search.mjs`: 역사 영상 고정 검색어 제거. 임의 사업 아이디어를 서비스/콘텐츠/혼합으로 조사하는 세 가지 검색문. 무료 Tavily SDK는 제한에 걸리면 실패로 알림. Gemini/OpenAI 키는 읽을 수 있어도 유료 API 호출하지 않음.
- `bin/opportunity-lab.mjs`: 로컬 상태 복구, 후보 등록, 사용자 근거 입력, 기준점 감사(`POST /api/analyze`), WJ 반려, **조건부 승인 검수**, 복원 자산 인계 차단, 실제 Markdown 감사 보고서(`GET /api/report.md`), 실물 URL 연구 보고서 열기. 다른 공정 자동 실행 없음.
- `lib/governed-pipeline.mjs`: 근거 링크의 기관/업체 독립성, 원본 캡처 식별자·SHA-256, 사실·추정·UNKNOWN, 유료 수요 증거, 성장 시계열, 비교 대상 3개, 이용 권리, 영상/서비스 원가, 최소 검증된 전략 3개 등 독립 감사. **읽기 전용 Golden 7×7 정본이 검증되지 않으면 승인 차단.**
- `lib/strategy-report.mjs`: 확인된 근거와 미확인 사실을 분리한 아이디어별 Markdown 보고서. 매출/성장/성공 가능성 수치를 지어내지 않음.
- `lib/reuse-index.mjs`: 기존 포크의 `rebiz` 실행기, 공개 근거 수집기, REA import, 사이트 시작 코드, clone-check, apply-plan의 경로/소스 SHA-256 목록. 복사나 수정 없이 원본 링크만 사용. 현재 수준 `UNIT_TESTS_ONLY` → 제작 승인 불가.
- `viewer/business-pipeline.html`: 실제 로컬 실험 화면. 입력/검색/후보/근거/감사/보고서/반려/승인 검수/REA 자산/제작 인계 순서.
- `test/governed-pipeline.test.mjs`, `test/governed-api.test.mjs`: 업종별 검색, 자체 회사 근거의 독립 검증 사칭, 미캡처 자료 차단, Golden 정본 부재, 확인 문구·해시 누락 차단, 자산 QA 미완료, 중복 후보 재검색 제외를 검증. 모든 테스트는 로컬 주소, 가상 URL·가상 자료를 이용하며 유료 AI/API 호출 없음.

## 기능별 정확한 상태

| 기능 | 실제 상태 |
|---|---|
| 입력된 아이디어별 검색문 생성 | CODE_PASS, 업종 고정 단어 제거 |
| Tavily 외부 검색 | 기존 무료 실검색 이력, 제한/한도 있음. 이번 수정에 대한 다양한 분야 라이브 실검색은 별도 검증 필요 |
| 10개 후보 추적/중복 제거 | 로컬 상태 및 가짜 후보 통합테스트 PASS |
| 외부 업체의 독립 실제 운영·유료 고객 확인 | **HOLD**: 수집 원본·유료 고객 데이터 자동 취득 불완전 |
| 사업 전략 자동 완성 | 증거 없으면 0개로 차단. 실제 자료 3개가 확보되어야 전략 검증 가능 |
| Golden 7×7 정본 대조 | **BLOCKED**: 공식 승인 49문항 원본 경로·해시 확인 필요, 변경 금지 |
| WJ 승인 경로 | 검증과 명시 확인 없이는 409. 로컬 입력은 신원 인증이 아니므로 운영용 인증 추가 필요 |
| REA 복원 자산 목록 | 로컬 6개 소스 검색, 경로/해시/기능 표시 |
| 승인 후 빌드 준비 | READ_ONLY_HANDOFF 게이트만 마련. 실제 독립 실행기 자동 제작은 **미구현** |
| 원본 REA/3×3/7×7 | 수정하지 않음, main 유지 |
| 유료 API/게시/배포/고객 연락 | NOT_EXECUTED |

## 원본 검증 정책

- 한 회사가 작성한 소개, 리뷰, 가격표는 **공급자 주장(SOURCED)**. 성공률·성장률 증거로 사용 금지.
- 사용자 입력 URL에 임의 해시를 붙여도 **자동 VERIFIED** 불가. 원본 캡처 기록과 출처 도메인 대조가 필요. 현재 수동 입력 자료는 해시를 저장하지 않고 검증되지 않은 것으로 표시.
- 역사 영상은 단일 실험 **예시**. 새로운 분야의 자동 분석 결과로 재활용 금지.
- 사업 기회 우선 순위는 근거 확보량에 따른 **추가 연구 순위**. 가설 점수를 성공 가능성 %로 재표시 금지.
- 유료 고객 인터뷰, 거래 실적, 증거 시점, 경쟁사 확인, 규제/저작권 허용이 확인되지 않으면 최종 결론 **HOLD**.
- WJ 사업 전략 승인과 기존 Golden 문서 개정 승인은 별개. Golden 자체 수정 요구가 오면 3회 독립 확인 및 WJ 최종 명시 승인 규칙을 따라야 하고 원본은 변경하지 않음.

## 원본 기술 재사용의 구체적인 방법

WJ 승인 전에 `rebiz build`/apply/배포 금지. 승인된 전략은 SHA-256으로 고정하고, 검증된 복원 자산의 URL/경로, 버전, 라이선스, 테스트 근거를 선택한다.

차후 승인·QA를 통과하면 기존 **`rebiz` 공개 도구**의 `collect` → `from-rea` → `check` → `build` → `check-clone` → `apply-plan`을 선택적으로 재사용한다. 타사 코드·문구·브랜드/이미지/자산을 복사하지 않고 **독립된 고객가치와 디자인을 가진 결과**를 만든다.

## 로컬 재현 (Windows)

```powershell
cd C:\Users\admin\AppData\Local\Temp\aiba-rebiz-fork-dev-20261121
npm test
node bin\opportunity-lab.mjs
# PC 브라우저에서 http://127.0.0.1:4178/
```

- 검색: 아이디어 → '실제 URL 검색 실행' (Tavily 한도에 걸리면 사용자가 허락한 공개 URL을 수동 등록)
- 검증: 10개 후보의 출처·독립 자료 → '현재 후보 근거 감사' → 보고서 출력/원본 링크 확인
- 반려: WJ 사유를 남기면 다음 회차에 기존 후보가 제외됨
- 승인: 임시 7개 축을 공식 Golden 7×7으로 위장하거나 WJ 입력을 임의 대리하지 않음
- 자산: 기존 6개 원본 경로/해시를 조회만 하며 SOURCE_PRESENT ≠ 독립 제품 QA PASS
- 사용자의 역사 영상 30초 Blender 결과물은 독립적인 제작 **실험 자산**이지, 고객 지불의사 검증이나 ReverseBusiness 사업전략 승인 증거가 아님

## 다음 구현에 필요한 세 가지 기술 과제 (WJ 확인 전 Golden 수정 금지)

1. 승인된 Golden 7×7 정본 읽기 전용 검증·해시 연결 (정본 개정 아님)
2. 포크에 이미 있는 `collect`/REA Evidence를 10개 사업 후보의 독립 캡처·근거 해시 검증에 연결하여 실제 재조사 자동화
3. 인증된 WJ 사업 승인과 제품 제작 권한을 분리하고, 검증된 복원 모듈을 **독립 실행기**로 구성하는 빌더/QA

**구현 착수 지시가 아니라 현재 완성·미완성 경계를 기록한 개발 문서.** 이번 지시 범위는 별도 개발 브랜치 내 코드 수정과 QA·GitHub push이며, 사업 승인·유료 실행·외부 배포는 포함되지 않는다.
