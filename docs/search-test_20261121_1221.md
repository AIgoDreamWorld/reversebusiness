# GOAL — 실제 검색 엔진 연결 및 후보 10개 실증
시점: 2026-11-21 KST. 프로젝트: ReverseBusiness / Opportunity Lab.
입력 아이디어: **AI 역사 다큐멘터리 영상을 학교·박물관에 공급하는 서비스**.

## 결과와 판정
- **Tavily 공식 JavaScript SDK** `@tavily/core`의 API 키 없는 공유 한도 검색을 실전 실행: PASS
- 검색 호출: 2회 (`requestId=336c5583-01e7-4d9a-b51b-d60c042698f3`, `7ae02eba-fc59-45f8-8f13-c25316b316ce`); 검색 결과 원문 20건.
- 후보 필터 기준: 원본 URL 유지, 중복 서비스 도메인 배제, 뉴스 기사·커뮤니티·비교글·원시 동영상 URL을 서비스 후보로 세지 않음.
- 정밀 필터 후 확보한 실제 서비스 URL **8개** + 별도 공식 공개 웹 검색에서 교차 확인한 **2개(Mootion, Stillscope)** = **고유 서비스 도메인 10개**.
- 앱 로컬 API `/api/discover`로 10개 등록: `DISCOVERED=10`; `/api/state` 재조회: `searchEnabled=true, candidates=10`.
- Edge 무인 브라우저로 실제 앱 화면에 10개 목록과 `10 증거 부족` 표시 확인.
- **사업성 판정:** 10개 모두 DISCOVERED / 7×7 확인 0 / 독립 검증 0 / HOLD. 순서는 검색 발견순이며 매출 순위, 성공 가능성 순위가 아니다.
- Tavily 공유 무료 일일 한도에 도달: 이후 실시간 검색 요청은 제한. 키를 만들거나 유료 서비스를 신청하지 않았음. 저장된 검색 근거 10개를 등록해 앱에서 검토 가능하게 했음.
- 별도 API 키·청구·외부 배포 없음. 기존 원본·Golden·main 미수정.

## 재현
```powershell
cd <ReverseBusiness 프로젝트 루트>
npm install --no-save --no-package-lock --ignore-scripts @tavily/core
node bin/opportunity-lab.mjs
# PC 브라우저: http://127.0.0.1:4178/
node --test test/opportunity.test.mjs
npm test
```

`@tavily/core`는 실험 PC의 무시되는 `node_modules`에만 설치. 기존 `package.json`, 잠금 파일, 원본 의존성 정책 미변경. API가 재검색 가능한지는 공유 한도에 좌우됨. 새 PC에서는 같은 비커밋 설치를 수행해야 함.
