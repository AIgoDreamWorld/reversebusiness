## 주요 결함을 어떻게 막았는가?

1. 업종 고정 검색문 제거. 임의 아이디어 입력 시 이전 역사 다큐 단어가 섞이지 않는 시험 PASS.
2. 검색 URL 10개만으로 사업 성공 확률, 매출, 3개 합격 전략을 꾸며내지 않음.
3. 사용자 입력에는 원본 캡처 해시가 들어가지 않도록 서버에서 제거. 공급자 자료를 독립 출처로 위장하지 않음.
4. 3개 연구 대상은 우선 증거량 정렬이며 성공률·성장률·수익성 점수가 아님.
5. 원본 REA 6개 자산은 QA `UNIT_TESTS_ONLY`로 표시. 원본 복제와 독립 실행기 자동 제작 차단.
6. 실제 WJ 전략 승인과 로컬 폼 입력을 구별. 현재 Golden 7×7 정본 불명으로 승인 차단.
7. 기존 역사 영상 수동 보고서를 모든 아이디어의 자동 분석 결과로 사용하지 않음. `/review`는 별도 과거 사례로 유지.
