## 실전 수집
- 실제 대상: Fliz 역사 영상 소개 https://fliz.ai/ai-history-video-generator
- 호출: WJ 작업실 `POST /api/capture` (명시적 `공개 페이지 수집` 문구 확인)
- **기존 `skill/reversebusiness/tools/collect.mjs` 직접 재사용:** `--pages 1 --no-render` (사용자 폼 제출/로그인/결제/REA 유료 모드 없음)
- 실제 공개 GET: 2건 (robots 확인 포함)
- 결과: `PUBLIC_SUPPLIER_PAGE_CAPTURED_NOT_VERIFIED`
- 원본 수집기 Terms 상태: `robots-only`
- 증거: 원본 파일 `report.json`, `source.json`, `requests.json` 로컬 무시 폴더에만 보존, `report.json` SHA-256 생성
- 사용자 인터페이스: Fliz 카드에 공급자 공개 페이지 `SOURCED` 표시
- 근거 감사: **Fliz SOURCE 1/7 / 독립검증 0/7 / 전체 HOLD** (매출/구매 의사/미래 성장 수치 위조하지 않음)
- 원본 수집기 코드, Git main, 승인된 Golden/3×3/7×7 무변경

## 추가 안전 검사

1. 사용자 입력의 사설망/localhost/커스텀 포트/쿼리 토큰 URL을 수집 대상으로 보내지 않는 테스트 PASS
2. DNS 응답에 사설 IP가 섞이면 실패로 멈추는 테스트 PASS
3. 원본 수집 결과가 후보 URL과 다르거나 GET 이외 요청이 있으면 거부하는 테스트 PASS
4. 원본 파일 SHA-256 생성 검사 PASS
5. 승인 없는 후보 수집 요청은 403으로 거부하는 API 통합 테스트 PASS
6. 승인되지 않은 사업 전략/REA 자산 제작 인계 차단 테스트 PASS

## 전체 자동 테스트

## 아직 해결되지 않은 차단 사항

- **사업 성공 보증:** 불가능. 독립 고객 지불 의사·경쟁사 성과·중장기 시계열 증거가 없으면 HOLD
- **자동 후보 10개 전체 재실사:** 기존 수집기는 현재 사용자 선택 1업체씩 수집, 일괄 수집/독립 출처 자동 대조는 미구현
- **Golden 7×7 공식 정본:** 아직 읽기 전용 인증 및 49개 문항 경로가 연결되지 않아 자동 사업 승인 BLOCKED
- **사업 전략 3개 검증:** 현재 유효 전략 0개, WJ 승인 경로 차단 상태
- **REA 복원 자산 → 독립 실행기:** 6개 자산 원본 발견/해시 연결은 완료. 원본 자산의 실제 통합 제작·독립 실행·출시 QA는 승인 전 미실행.
- DNS 변경·외부 사이트 리다이렉트 등 네트워크 경계에서 다중 주소 검증 보강 필요. 기존 REBiz 수집기의 접근 제한·robots 정책을 우회하지 않음.
